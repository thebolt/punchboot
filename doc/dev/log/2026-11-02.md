  soundness, the real code, extensions), in `verification.md`. D-022.
- `tests/cbmc`: `Makefile.common`, `common.h`, `stubs/string_models.c`, proofs `crc` and `wire`,
  mutants `crc-index-mask` and `wire-auth-list` (both found at 32 and 64 bit).
  `scripts/ci/cbmc.sh` and `scripts/pbdev cbmc`. The Dockerfile installs `cbmc` (6.6.0 in
  trixie), and `build.yml` has a non-blocking `cbmc` job for both word sizes.
- Builds use goto-cc with `-m32`/`-m64` against the firmware libc headers, so the proofs see the
  target type widths. CBMC's own string models are preprocessed with the host libc headers and
  fail at 32 bit without multilib, so the proofs use their own models with the standard
  preconditions as assertions.
